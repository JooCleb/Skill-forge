# Exemplo de projeto mínimo

**Objetivo:** converter uma lista de tarefas fornecida em uma tabela com tarefa e prazo, preservando lacunas.

**Gatilho:** pedido explícito dessa conversão. **Não usar:** quando o usuário quer que as tarefas sejam executadas.

Uma instrução suficiente pode ser: «Leia a lista; crie uma linha por tarefa; marque prazos ausentes como não informados; não invente datas». Este é um exemplo didático, não uma skill instalada nem um teste executado.
