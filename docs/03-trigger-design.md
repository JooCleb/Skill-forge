# Desenho de gatilhos

A descrição deve responder: qual objetivo do usuário indica esta skill? Acrescente condições de uso e exclusões quando elas realmente separam competências parecidas. Evite listar todas as palavras relacionadas ou declarar que a skill serve para qualquer tarefa.

Antes de finalizar, compare três grupos de pedidos: um que deve acionar, um que parece semelhante mas não deve, e um ambíguo cuja decisão dependa de contexto. Exemplo: uma skill de revisar citações pode se aplicar a «confira se estas fontes sustentam os trechos»; uma simples formatação de bibliografia é uma tarefa distinta.

Teste a seleção no ambiente real. Descrições longas podem perder visibilidade quando várias skills competem pelo contexto. Os limites não substituem testes de acionamento.
