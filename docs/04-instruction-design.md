# Desenho de instruções

Organize as instruções em torno de entrada, decisões, ação, verificação e saída. Coloque a ordem quando for necessária: por exemplo, ler uma fonte antes de afirmar que ela sustenta uma conclusão. Ao faltar um insumo indispensável, indique como buscar ou perguntar; se uma ferramenta não existir, ofereça um caminho alternativo que preserve o objetivo.

Use comandos verificáveis em vez de adjetivos vagos. «Associe cada conclusão relevante a uma fonte acessível» é mais acionável que «seja rigoroso». Não peça para inventar dados, supor permissões ou declarar sucesso sem verificar. Uma instrução deve respeitar solicitações do usuário e regras superiores do ambiente.

O formato de saída deve servir ao trabalho: uma matriz ajuda a mapear evidências, mas pode ser excesso para uma resposta simples. Evite impor relatórios internos, ciclos sem fim e passos que não mudam o resultado.
