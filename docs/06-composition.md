# Composição de skills

Skills podem ser usadas em sequência quando suas responsabilidades se complementam. Por exemplo, uma busca identifica fontes e uma verificação de citações examina a relação entre trechos e fontes já acessíveis. Defina a entrada e a saída de cada etapa e preserve as incertezas ao passá-las adiante.

Compor não exige criar agentes ou executar todas as skills possíveis. Se uma competência estiver indisponível, descreva uma alternativa executável no ambiente real. Use uma skill composta quando a sequência for recorrente e possuir um objetivo próprio; mantenha componentes separados quando também forem úteis isoladamente.

Para decidir entre ampliar e criar outra skill, consulte [fusão e divisão](10-merging-and-splitting.md).
