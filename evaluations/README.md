# Avaliações

Coloque desenhos de comparação em `benchmarks/`, casos de falhas anteriores em `regression/` e resultados efetivamente observados em `results/`. Cada registro deve indicar skill e versão, ambiente, entradas, critérios, evidência e limitações. Casos de exemplo são propostas até serem executados. Use o [modelo de avaliação](../templates/evaluation.md).
