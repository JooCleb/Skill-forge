# Incubadora

Área para desenvolver ideias antes de incluí-las no catálogo principal. Registre objetivo, hipótese, exemplos e estado; não confunda protótipo com skill avaliada. Use `experiments/` para comparar ideias, `prototypes/` para primeiras versões e `candidates/` para versões prontas para avaliação. Uma ideia pode voltar a qualquer etapa.
